# Quickstart Copilot — プロダクト概要

> Skip the boring setup. Get to the part where you build.
> 面倒なセットアップは飛ばして、作る楽しさだけ手元に。

---

## このアプリは何か

**Quickstart Copilot** は、バイブコーダー（Lovable / Bolt / v0 / Cursor などのAIコーディングツールを使う人）が「アプリのアイデアはあるのにツールの接続でつまずく」という問題を解決する **Chrome 拡張機能**です。

GitHub アカウントの作成、SSH 鍵の登録、API キーの発行、Vercel へのデプロイ——こういった「コードを書く前の面倒なセットアップ作業」を、ブラウザを自動操作して代わりにやってくれます。

---

## 誰のためのアプリか

| ターゲット | 具体的な悩み |
|---|---|
| AIコーディングツールを使う非エンジニア | アプリは作れるが GitHub・Vercel・Supabase の初期設定でつまずく |
| バイブコーディング初学者 | セットアップに時間がかかりすぎて挫折してしまう |
| 同じ手順を何度も繰り返す開発者 | 毎回同じ 10 ステップをプロンプトに書き起こすのが面倒 |

---

## できること（主要機能）

### 1. レシピカタログから選んで実行

事前定義された「レシピ」（自動化シナリオ）をカタログから選んで実行するだけ。難易度・所要時間・必要な手動操作が事前にわかるので安心して任せられます。

**v1 対応レシピ一覧**

| レシピ | 対象サービス | 難易度 |
|---|---|---|
| GitHub アカウント作成 | github.com | 初級 |
| GitHub に SSH 鍵を登録 | github.com | 中級 |
| Anthropic API キーの発行 | console.anthropic.com | 初級 |
| OpenAI API キーの発行 | platform.openai.com | 初級 |
| Supabase プロジェクト作成 | supabase.com | 中級 |
| Vercel に初めてデプロイ | vercel.com | 中級 |
| Cursor の初回サインイン | cursor.com | 初級 |
| Lovable と GitHub を接続 | lovable.dev | 中級 |

### 2. 「任せながらも、いつでも止められる」安心感

- 実行中はサイドパネルに現在のステップ・進捗・次の操作が常時表示される
- OAuth認証・メール認証・「この鍵は一度しか表示されません」など、**人間が対応しなければならないポイントで自動的に一時停止**し、再開を促す
- いつでも停止・キャンセル可能。拡張機能がブラウザを乗っ取ることはない

### 3. 初回セットアップウィザード

インストール直後に 3 ステップのウィザードが起動し、5 分以内に最初の成功体験を得られるよう設計されています。

1. **言語を選ぶ** — 日本語 / English
2. **API キーを登録する** — スキップして後で設定も可
3. **最初のレシピを選ぶ** — すぐに実行開始できる

### 4. 日英バイリンガル対応

UI・レシピの説明・エラーメッセージ・ヘルプテキストまで、すべて日本語と英語の両方に対応。設定画面からいつでも切り替えられます。

### 5. Open-ended モード（上級者向け）

レシピに無い操作をしたい場合は、自由形式のゴールを入力して AI に任せることもできます。

---

## 動作の仕組み（ユーザー視点）

1. Chrome 拡張機能をインストール
2. サイドパネルを開いてレシピを選ぶ
3. 「実行する」をタップ
4. Quickstart Copilot が適切なページを開き、フォームを埋め、ボタンを押していく
5. 人間の介入が必要なタイミング（OAuthポップアップ、メール確認など）で一時停止し、「続けてください」と案内
6. 完了通知が届いたら作業終了

## 競合との違い（現在の位置づけ）

| 比較軸 | Quickstart Copilot | ChatGPT/Claude ブラウザ操作 | Manus / Atlas などの汎用 AI エージェント |
|---|---|---|---|
| 対象範囲 | バイブコーディング周辺の特定フロー（15 種程度） | 何でもできるが導線が薄い | 何でもできる |
| 初学者への配慮 | 難易度・所要時間・介入ポイントが事前にわかる | なし | なし |
| 操作の透明性 | ステップごとに何をしているか常時表示 | ブラックボックス気味 | ブラックボックス気味 |
| バイリンガル対応 | 日英完全対応 | 英語中心 | 英語中心 |
| コスト | Rules only モードなら API コスト 0 | 毎回 API コストかかる | サブスク / 従量課金 |
| プライバシー | ローカルストレージのみ・スクショ不送信 | クラウド送信あり | クラウド送信あり |

## 設定でカスタマイズできること

| 設定項目 | 選択肢 |
|---|---|
| 動作モード | Rules only（API コスト 0）/ Hybrid（推奨）/ AI only |
| 言語 | 日本語 / English |
| 実行速度 | 遅い / 普通 / 速い |
| API キー | Anthropic API キー（Hybrid / AI only モード時に必要） |
| ページ読み込み時の自動起動 | オン / オフ |

---

## プライバシー・セキュリティ

- すべての設定はブラウザのローカルストレージに保存（クラウド同期なし）
- AI ドリブンモード時にAnthropicへ送信するのは「URL・タイトル・ボタン/入力欄のラベル」のみ
- スクリーンショット・クリップボード・フォームの入力値・ページ本文は**送信しない**
- API キーはローカルにのみ保存され、`api.anthropic.com` にのみ送信

---

## 現在の制限

- Chromium 系ブラウザのみ対応（Chrome、Edge 等）
- クロスオリジン iframe 内の操作は不可
- Shadow DOM（closed）の要素は操作不可
- レシピ外のサービスは Open-ended モードで対応
