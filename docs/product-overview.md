# Quickstart Copilot — プロダクト概要

> Skip the boring setup. Get to the part where you actually work.
> 面倒な初期設定や操作の壁は飛ばして、本来やりたい仕事だけ手元に。

---

## このアプリは何か

**Quickstart Copilot** は、**kintone / Lステップ / Chatwork / Slack といった BtoB SaaS ツールを導入したものの「非 IT メンバーに操作を教えるのが大変」** という現場の悩みを解決する **Chrome 拡張機能**です。

画面上に "セカンドカーソル" が現れ、「次にここを押します／理由はこうです」と一つずつ案内しながら、レシピ（手順書）に沿ってブラウザ操作を代行・ガイドします。エンドユーザーが自分でインストールして使える点が、企業契約前提の WalkMe / テックタッチとは異なる独自の立ち位置です。

バイブコーディング（Lovable / Cursor / Supabase / Vercel など）周辺のセットアップレシピも引き続き同梱しており、副カテゴリとして利用できます。

---

## 誰のためのアプリか

| ターゲット | 具体的な悩み |
|---|---|
| BtoB SaaS の現場リーダー（一次） | kintone のカスタム画面・Lステップのシナリオ・Chatwork タスク・Slack 運用を非 IT メンバーに教えるのが大変 |
| 非 IT のエンドユーザー（一次） | 毎回どこを押せばいいか分からない／マニュアルを読んでも迷う |
| バイブコーディング初学者（二次） | GitHub・Vercel・Supabase の初期設定でつまずく |
| 同じ手順を繰り返す担当者 | 毎回同じ十数ステップを口頭やマニュアルで説明するのが非効率 |

## できること（主要機能）

### 1. レシピカタログから選んで実行（BtoB レシピを先頭固定）

事前定義された「レシピ」をカタログから選んで実行・ガイドするだけ。難易度・所要時間・必要な手動操作が事前にわかります。**BtoB ツールのレシピ（`btob-tool` カテゴリ）はカタログ先頭に固定表示**され、検索時もブーストされます。

**v1 対応レシピ一覧**

| レシピ | 対象サービス | カテゴリ | 難易度 |
|---|---|---|---|
| kintone アプリ内ナビゲーション | *.cybozu.com | BtoB ツール | 初級 |
| kintone レコード作成 | *.cybozu.com | BtoB ツール | 初級 |
| Chatwork タスク追加 | chatwork.com | BtoB ツール | 初級 |
| Chatwork グループ作成 | chatwork.com | BtoB ツール | 初級 |
| Slack チャンネル作成 | app.slack.com | BtoB ツール | 初級 |
| Lステップ シナリオ確認 | step.lme.jp | BtoB ツール | 初級 |
| GitHub アカウント作成 | github.com | 開発セットアップ | 初級 |
| GitHub に SSH 鍵を登録 | github.com | 開発セットアップ | 中級 |
| Anthropic / OpenAI API キーの発行 | console.anthropic.com 他 | 開発セットアップ | 初級 |
| Supabase / Vercel / Cursor / Lovable | 各サービス | 開発セットアップ | 初〜中級 |

> 注意: kintone / Lステップ などは画面が組織ごとに大きくカスタマイズされ得ます。標準レシピがあなたの画面に必ず一致するとは限りません。合わない場合は **レシピ録画機能** で自社専用版を作れます。

### 2. ライブカーソル（「乗っ取られ感」の排除）

AI が画面を操作する前に、**必ず**「次に何をするか／なぜするか」を 1 行ラベルで提示し、200〜600ms 滞留してからクリック／入力します（Auto モードでも例外なし）。`prefers-reduced-motion` 環境ではアニメーションのみ抑止し、情報伝達のための滞留は維持します。

### 3. 「任せながらも、いつでも止められる」安心感

- 実行中はサイドパネルに現在のステップ・進捗・次の操作が常時表示される
- OAuth 認証・メール認証・「この鍵は一度しか表示されません」など、**人間が対応すべきポイントで自動的に一時停止**
- いつでも停止・キャンセル可能。対応外ページ（`chrome://` 等）では分かりやすいエラーでカタログに戻る

### 4. レシピ録画（自社専用レシピの内製）

カタログの「自分のレシピを録画する」から、クリック／入力操作を録画して Recipe JSON を生成・エクスポートできます。録画はローカル完結（クラウド送信なし）。パスワード・クレジットカード・OTP 等の機微入力は録画スキップ。録画はオプトイン（ボタンを押すまで一切作動しません）。

### 5. 初回セットアップウィザード

インストール直後に 3 ステップのウィザードが起動します。

1. **言語を選ぶ** — 日本語 / English
2. **Gemini API キーを登録する** — [Google AI Studio](https://aistudio.google.com/app/apikey) の無料枠で 0 円スタート可。スキップしても Guide モードのデモは試せます
3. **最初のレシピを選ぶ** — すぐに実行開始

### 6. 日英バイリンガル対応 / Open-ended モード

UI・レシピ説明・エラー・ヘルプまで日英完全対応。レシピに無い操作は自由形式ゴールを AI に任せることもできます。

## 動作の仕組み（ユーザー視点）

1. Chrome 拡張機能をインストール
2. サイドパネルを開き、先頭の BtoB レシピ（または検索）から選ぶ
3. 「実行する」をタップ
4. セカンドカーソルが「次はここ／理由」を見せながら操作を代行・ガイド
5. 人間の介入が必要なタイミングで一時停止し、案内
6. 完了通知が届いたら終了

## 競合との違い（現在の位置づけ）

| 比較軸 | Quickstart Copilot | WalkMe / テックタッチ | Layup / HowdyGo | 汎用 AI エージェント |
|---|---|---|---|---|
| 導入主体 | **エンドユーザー自発導入**（Chrome 拡張） | 企業契約・SaaS 提供側へ実装 | 企業向けデモ作成 | 個人 |
| 対象 | BtoB ツール操作 + 開発セットアップ | 任意の Web アプリ | プロダクトツアー | 何でも |
| 透明性 | ステップごとに何を／なぜを常時表示 | ツールチップ中心 | ガイド中心 | ブラックボックス気味 |
| バイリンガル | 日英完全対応 | 製品依存 | 英語中心 | 英語中心 |
| コスト | 既定 Gemini（AI Studio 無料枠で 0 円可）/ Rules only で 0 | 企業ライセンス | 企業ライセンス | サブスク / 従量 |
| プライバシー | ローカルのみ・スクショ不送信・録画もローカル | クラウド | クラウド | クラウド送信 |

## 設定でカスタマイズできること

| 設定項目 | 選択肢 |
|---|---|
| AI プロバイダー | **Gemini（既定・低コスト）** / DeepSeek / Anthropic / OpenAI |
| 既定モデル | `gemini-2.5-flash-lite`（`at_model` 未設定時） |
| フォールバック | エラー時に自動リトライ（既定 Anthropic） |
| 動作モード | Rules only（API コスト 0）/ Hybrid（推奨）/ AI only |
| 言語 | 日本語 / English |
| 実行速度 | 遅い / 普通 / 速い（カーソル滞留時間に反映） |
| API キー | Gemini を最初に登録（無料枠）。他プロバイダーは任意のフォールバック |
| ページ読み込み時の自動起動 | オン / オフ |

## プライバシー・セキュリティ

- すべての設定はブラウザのローカルストレージに保存（クラウド同期なし）
- AI ドリブンモード時に送信するのは「URL・タイトル・操作可能要素（ボタン/入力欄）のラベル」のみ。フル DOM やスクリーンショットは送らない
- スクリーンショット・クリップボード・フォーム入力値・ページ本文は **送信しない**
- API キーはローカルにのみ保存され、既定では `generativelanguage.googleapis.com`（Gemini）にのみ送信。プロバイダー切替時は各社エンドポイント
- 録画レシピ（`at_user_recipes`）はローカル完結。明示的な JSON エクスポート時のみブラウザ外に出る

---

## 現在の制限

- Chromium 系ブラウザのみ対応（Chrome、Edge 等）
- クロスオリジン iframe 内の操作は不可 / Shadow DOM（closed）は不可
- 対応外ページ（`chrome://`、ストア配信前ページ、OAuth サブウィンドウ等）では実行不可（フレンドリーなエラーでカタログに戻る）
- 録画レシピのチーム共有は未対応（Phase 4 予定。v1 はローカル + 手動 JSON 受け渡し）
- BtoB ツールは組織ごとに画面が異なり得る（標準レシピが万能ではない／録画で自社版を作成）
