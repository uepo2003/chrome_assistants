何が起きたか

仕組み

Manifest V3 コンテンツスクリプトの寿命

Chrome 拡張機能のコンテンツスクリプトは 「そのページのライフサイクル」と一蓮托生です。 ページが消えればスクリプトも消えます。今回はこの仕様を踏み抜きました。

  1. aliveユーザーが github.com を開く → 拡張機能のコンテンツスクリプトが注入され、main.js の IIFE が実行
  2. aliveSide Panel から STEP_START が届く → handleStepStart が走り、runMode = 'step'、ステップループ開始
  3. aliveAI 呼び出し → クリックを返す → action-executor が実クリック発火
  4. deadクリックがリンクをたどる → ブラウザがナビゲーションを開始 → 古いページの全 JavaScript コンテキストが破棄される（setTimeout も Promise も）
  5. new新しいページが読み込まれる → 拡張機能のコンテンツスクリプトが再注入される → main.js が再実行されるが runMode は null（IIFE スコープが新しい）
  6. dead誰も次のアクションを要求しない → 新しい main.js は STEP_START を受け取っていないのでループを開始しない → 無音停止
修正

4つの修正で確実に進行＆失敗が見える化

二度と「無音停止」を起こさないため、原因対処（自動再開）と症状対処（明示化）の両面から手を入れました。

①

ナビゲーション自動再開

background/service-worker.js

chrome.tabs.onUpdated リスナーで、実行中のタブが status: 'complete' になったことを検知 → 同じ stepIndex で STEP_START を再送。 新しいページのコンテンツスクリプトがちゃんとループ再開できる。

  • 800ms のデバウンスで重複防止
  • 1ランで最大 8 回までナビゲーションを許可（無限ループ防止）
②

失敗の明示 narration

content/main.js → sidepanel

今までは「silent noop」で消えていた以下のケースを、赤い「!」アバター付きで必ずチャット表示。

  • Couldn't find target on page — targetId が解決できない
  • Action didn't take effect — クリックは発火したが効いてない
  • Reached max iterations — 6回試行で進展なし
  • Couldn't make progress — 連続ノーオペ上限
③

構造化エラーログ

common/error-capture.js → options

すべての warn() が自動的に 200件の dev log リングバッファに集約。 Options ページの Developer セクションで確認できる。

  • ソース別カラータグ (content / sidepanel / background)
  • ms 精度タイムスタンプ・スタックトレース折りたたみ
  • 新規エラーは Auto-refresh で即時追加表示

コード変更（要点）

背景SWに追加した16行

原因対処の核は chrome.tabs.onUpdated リスナー1個です。 

// background/service-worker.js
chrome.tabs.onUpdated.addListener((tabId, changeInfo, tab) => {
  if (changeInfo.status !== 'complete') return;
  const run = runByTab.get(tabId);
  if (!run || run.status !== 'running') return;
  if (!Array.isArray(run.plan)) return;
  if (run.currentStepIndex >= run.plan.length) return;

  // loop guard + debounce omitted...

  broadcastToSidepanel({
    type: MSG.STEP_PROGRESS,
    narration: 'Page navigated — resuming step',
    action: 'navigated',
    detail: tab.url,
  });

  // Wait for content scripts to inject, then re-emit STEP_START.
  setTimeout(() => {
    chrome.tabs.sendMessage(tabId, {
      type: MSG.STEP_START,
      stepIndex: run.currentStepIndex,
      step: run.plan[run.currentStepIndex],
      reason: 'page_navigated',
    });
  }, 600);
});
